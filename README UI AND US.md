# Student Expense Tracker

A low-fidelity mobile app wireframing project designed for college students to track and manage daily expenses.


- User Login / Sign Up
- Expense Dashboard
- Add Expense
- Expense Categories
- Expense List
- Profile / Settings

User Flow
Open App → Login
 Sign Up → Home
 → Add Expense 
 → Save Expense → 
 View Expense List →
 Profile
  Settings

 Design Thinking Process
1. Empathize — Understand student needs and problems.
2. Define — Identify the main expense-tracking problem.
3. Ideate — Plan simple features and user flows.
4. Prototype — Create low-fidelity wireframes.
5. Test — Collect feedback and improve the flow.

 Tools Used
- Figma
- UI/UX Wireframing
